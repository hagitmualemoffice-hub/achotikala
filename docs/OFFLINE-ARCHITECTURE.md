# ארכיטקטורת גרסת האופליין (NetFree) — מוגן, לא לשנות בלי לקרוא

גרסת האופליין היא קובץ HTML אחד שנפתח מ-`file://` ומרכיב את האתר מתוך IndexedDB מקומי.
היא בנויה לעבוד מאחורי סינון תוכן (NetFree), ולכן יש כאן אילוצים שאינם "העדפות עיצוב".

## מה אסור לשבור (אינוריאנטים)

| כלל | למה |
| --- | --- |
| תעבורה רק דרך `<script src>` | `fetch`/XHR/ZIP/`.bin` נחסמים או נופלים ב-`file://` |
| חלק = 32KB גולמי (`CHUNK_RAW`) | מעל ~50–90KB מטען בינארי נחסם |
| `masked = 0` בחלקים חדשים | תוכן "רגיל" עובר סינון טוב יותר. `XOR_KEY` נשמר לפענוח חלקים ותיקים בלבד |
| ערבול 24 הבתים הראשונים בקבצים בינאריים (`HDR_LEN`/`HDR_XOR`) | תגובה שמתחילה בחתימת JPEG נחסמה בפועל |
| חתימת `AK.part(hash, index, total, b64, masked)` | קבצי החלקים והקובץ הפותח חייבים להסכים |
| חתימות DJB2 + שדות מניפסט `u`/`l`/`c` | אימות אורך וחתימה לכל חלק ולקובץ המורכב |
| שם חלק כולל את ה-hash (ו-`h` כשהחתימה מעורבלת) | תוכן שונה = כתובת שונה, אחרת מטמון CDN מגיש תוכן ישן |
| שמירת חלקי הגרסה הקודמת | משתמשת באמצע עדכון לא תקבל 404 |
| `health-check` מסמן `verified` מיד אחרי שהאפליקציה עלתה | אחרת שתי סגירות מהירות מבטלות עדכון תקין |
| rollback אוטומטי לגרסה הקודמת אחרי שני כשלונות פתיחה | מונע התקנה תקועה |
| טיפול ב-`onabort` של IndexedDB ובחוסר מקום | שגיאות אמיתיות שנצפו בשדה |

תמונות: כל קובץ מדיה צריך להיות מתחת ל-500KB (ורצוי מתחת ל-300KB), WebP.
`pack-offline.mjs` מתריע על כל חריגה.

## המרכיבים

- `offline/launcher.html` — קובץ הפתיחה (BOOT_REV 10). תבנית: `__UPDATE_ORIGIN__` מוחלף בזמן בנייה.
  `?origin=https://…` מאפשר בדיקה מול מקור אחר.
- `offline/config.json` — הריפו הציבורי ב-GitHub שממנו jsDelivr מגיש, והתיקיות שאינן נארזות.
- `scripts/offline-shared.mjs` — הקבועים המשותפים (חלק, ערבול, DJB2).
- `scripts/pack-offline.mjs` — אורז את `offline-dist/` לחלקים + מניפסט תחת `offline-cdn/`.
- `scripts/build-offline-package.mjs` — בונה את קובץ ההתקנה העצמאי (seed מוטמע).
- `scripts/verify-offline-publish.mjs` — אימות מקומי (`--local`) ואימות מול jsDelivr.

## שני ערוצים

```text
התקנה ראשונה:  Google Drive  ->  ארבעה קישורים קבועים וזהים (כל התוכן מוטמע, אפס בקשות רשת)
עדכונים:        GitHub ציבורי ->  cdn.jsdelivr.net/gh/<owner>/<repo>@main/offline-cdn
```

ה-seed המוטמע משתמש באותם חלקים, אותן חתימות ואותה לוגיקת אימות — רק שהחלק מגיע
מהקובץ עצמו (`AK.seedPart`) במקום מהרשת. בניסיון חוזר לאחר כשל, אותו חלק נמשך מהרשת.

## מה בכוונה לא נוגעים בו

`achotikala.com/auth-bridge` (התחברות מתוך `file://`), `window.ACHOTIKALA_OFFLINE_HOST` +
HashRouter, ופונקציית `sync-offline-content` שמעדכנת תוכן דינמי (אירועים/פוסטים/פודקאסט).
